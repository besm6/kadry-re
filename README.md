# kadry-re
Decompiling the HR database system, consisting of several programs.

The binary locations of the sub-blocks on the 2148 disk image are:

- Zone 0540 - the main program (КАДРЫ)
- Zone 0545 - questionnaire input (АНКЕТА)
- Zone 0553 - service block (service.pas)
- Zone 0560 - help for the service block and a few commands (school.pas)
- Zone 0565 - report generator
- Zone 0572 - field format help (fields.pas)
- Zone 1225 - database editing tool

The overlay mechanism expects the zone locations to be different, zone numbers "XORed" with 01000, i. e. 1540, 1545, etc., and 0225.

## Локальный запуск

```sh
make demo       # создать локальные тома, ввести учебные анкеты, проверить запуск
./run-kadry.sh  # работать с сохранённой базой
make check     # повторный запуск и проверка без изменения томов
```

Нужны Python 3, `dispak` с поддержкой `--725` и исходный
`/usr/local/share/besm6/2148`. Зависимости от соседних репозиториев нет.
Другой эмулятор задаётся через `DISPAK=/path/to/dispak`.
Запускалка использует собственный HOME в `build/home` и подключает
только локальные тома. Ввод и вывод — UTF-8, приказ заканчивается Enter.

При входе в КАДРЫ введите пароль `ПРОФ`. Примеры приказов:

```text
НАЙ ФИО,ПОД
УСТ ФАМ=ПЕТРОВА
НАЙ ФИО,ПОД
УСТ СБР
ДАЙ ПОЛ
ОТЧ
ИНФ
КАД
СЛУ
ВАЛЕТ
КАТ ПОК
КАД
КОН
КОНЕЦ
```

`ВАЛЕТ` — ответ на запрос пароля служебного блока. `КАД` возвращает
из служебного блока или отчётов к справкам. `КОН` выходит из КАДРЫ
в ПУЛЬТ; `КОНЕЦ` завершает ПУЛЬТ. При просмотре анкет программа может
спрашивать `ИДТИ?`; на этот запрос отвечайте отдельно.

Учебная база содержит шесть вымышленных сотрудников:

| Подразделение | Сотрудники | Зоны тома 2060 |
|---|---|---|
| ОТД 1 | Иванов Иван Иванович; Петрова Анна Сергеевна; Сидоров Петр Алексеевич | 0400–0401 |
| ЛАБ 1 | Кузнецов Алексей Петрович; Смирнова Елена Викторовна; Орлов Николай Андреевич | 0402–0403 |

Введены ФИО, пол, даты рождения и зачисления, образование,
семейное положение, специальность, адрес, телефон, должность и зарплата.
Разметка, создание подразделений и ввод всех анкет выполняются самой
исторической программой: [сеанс наполнения](sessions/populate.txt).
Справочники категорий создаются как небольшой учебный набор,
а не копия утраченной рабочей базы организации.

## Состав томов

Все номера зон и машинные адреса далее восьмеричные; номера томов —
десятичные. Оба образа имеют физический формат DISPAK: четыре начальные
служебные зоны, затем зоны по 1032 восьмибайтных слов (8 служебных и
1024 слова данных с тегами). Вместимость — 02000 зон, размер файла
8 487 168 байт. При копировании сохраняются все данные и теги,
служебные слова пересчитываются для нового тома и положения зоны.

| Файл | Назначение |
|---|---|
| `build/volumes/2068` | Минимальный ПУЛЬТ, программы КАДРЫ и загрузчик |
| `build/volumes/2060` | Постоянная учебная база и её справочники |
| `build/volumes/provenance.json` | Источник, SHA-256, карта копирования и адаптации |
| `build/volumes/demo.json` | Отметка об успешном наполнении |
| `build/logs/populate.{input,out,trace}` | Ввод, вывод и обмены сеанса наполнения |
| `build/logs/check.{input,out,trace,json}` | Сеанс проверки после перезапуска и его результат |

ПУЛЬТ перенесён с 2148:01000 в 2068:00000. Сохранены зоны каталога,
ДАЙ, АДСИС, СБОЙ, ЗГЛВК, КТЛБИБ, ПУСК, НАБЛ и БАВТ:
`0000, 0005, 0006, 0035, 0036, 0037, 0040, 0041, 0051`.
Системный каталог перечисляет только сохранённые файлы и запуск КАДРЫ.
В СБОЙ исправлен дескриптор списка архивов: слово `76012`
из `0010010000402667` заменено на `0010010000400037`.

Дополнительный каталог `КАДРЫ` находится в зоне `0100`.
В нём есть запускалка, монитор и все семь оригинальных программ;
смещения файлов отсчитываются от зоны каталога. Команда ПУЛЬТа:
`АРХ КАДРЫ,40,100`, затем `КАДРЫ`. Запускалка посылает их автоматически.

| Программа | Исходная зона 2148 | Зона 2068 | Число зон загрузки |
|---|---:|---:|---:|
| КАДРЫ / СПРАВ | 0540 | 1540 | 5 |
| АНКЕТА | 0545 | 1545 | 6 |
| СЛУЖЕБ | 0553 | 1553 | 5 |
| ШКОКАД | 0560 | 1560 | 5 |
| ОТЧЕТ | 0565 | 1565 | 5 |
| Справочник полей | 0572 | 1572 | 1 |
| РАБОЧ | 1225 | 0225 | 3 |

Число зон взято из дескрипторов переходов восстановленных исходников;
оно может превышать фактическую длину программы в заголовке.
Сохранившиеся справочные зоны `0755–0757` скопированы в `1755–1757`.

На 2060 каталог базы занимает зону `0160` (112 десятичное),
архив отчётов — `0275`, справочники — `0276–0277`.
Логическое устройство 40 несёт 2068, устройство 54 — 2060;
программы динамически подключают базу на устройство 52.

Подробная [структура базы данных](DATABASE.md) включает каталог,
битовые поля основной анкеты, справочники и отличия дополнительной базы.

## Совместимость и проверка

[Минимальный монитор](tools/monitor.py) — новый служебный код вместо
окружения «ТАМБОВ», на которое рассчитаны исходники. Он живёт в
`60000–61777`, переносит 56 слов контекста и командный TEXT через
входы `76021/76022`, загружает АДСИС и следующие оверлеи,
сохраняет область установок `67000` и восстанавливает резидент ПУЛЬТа
при выходе. Учебный оператор имеет права на все блоки; пароли блоков
проверяются оригинальной программой.

При загрузке главного блока монитор заменяет в памяти слово `03206`
(`3463000000000000` → `0010000000000000`): запрос физической таблицы
устройств в `L3173` не реализован в DISPAK. Это начальная проверка
дублирующихся дисков из `L3223(2060)`; в локальном паспорте диск
подключён однозначно. Дисковые образы семи программ не исправляются.

`make check` проверяет исходные слова и теги скопированных программ,
неизменённые части ПУЛЬТа, шесть анкет после нового запуска, выбор одной
фамилии, входы всех семи оверлеев по трассе Э70 и штатный выход.
Хеши обоих локальных томов до и после читающего сеанса должны совпасть;
отдельно проверяется неизменность исходного 2148.
Это проверка запуска и выбранных операций, не перекомпиляция `.pas`.
Расширенное редактирование и создание таблиц отчётов не проверялись.
Внешние службы «ТАМБОВ», включая `ЛИН`, в этот минимальный комплект
не входят; утраченные справочные страницы не воссоздаются.

Повторное `make demo` не вводит дубликаты. Для отдельной чистой копии:

```sh
python3 tools/demo.py --volumes /tmp/kadry-demo/volumes
KADRY_VOLUMES=/tmp/kadry-demo/volumes ./run-kadry.sh
```

Сборщик `tools/build-volumes.py --source /path/to/2148 --output DIR`
создаёт только новые файлы и отказывается перезаписывать существующие тома.
Если запустить `run-kadry.sh` без предварительного `make demo`, он создаст
пустую учебную базу; её можно затем наполнить командой `make demo`.
